# Historical research record

This directory preserves hypotheses, preregistrations, audits, negative results, and
claim-invalidation records from multiple exploratory phases. Files may describe different
models, token budgets, dataset constructions, and evidence standards.

They are retained for transparency, not presented as a single verified result set. The
maintained evidence status is `results/FINAL_CANONICAL_RESULTS.json`; the reproduction
gaps found in the public artifact are listed in `docs/repository-audit.md`.

Do not aggregate numbers across these documents or cite a value as reproduced without
tracing it to immutable prompt-level raw data, exact model/dataset revisions, and the
script that generated the aggregate.
